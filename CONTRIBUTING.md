# Contributing Guidelines

Thank you for considering contributing to our project! We welcome contributions from the community and appreciate your efforts to help improve our codebase. Please read the following guidelines before submitting a pull request or opening an issue.

---

# 1. Code of Conduct & Standards

1. **Code of Conduct**: All contributors are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). Please be respectful and considerate in all interactions.
2. **Clean code and encapsulation**: Follow best practices for clean code and encapsulation. Ensure that your code is readable, maintainable, and adheres to the project's coding standards.
3. **Documentation**: Update or add documentation as necessary. Clear and concise documentation is essential for the usability and maintainability of the project.
